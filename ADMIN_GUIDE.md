# Admin Guide: Papier Creations Website

Welcome to your new Content Management System (CMS). This guide will help you update products, categories, and brands without touching any code.

## 🚀 How to Start
1.  Double-click the **`start-website.bat`** file on your Desktop (or project folder).
2.  Two black windows will open. **Do not close them**. Minimize them.
3.  The ADMIN PANEL will open at: [http://localhost:1337/admin](http://localhost:1337/admin)
4.  The WEBSITE will open at: [http://localhost:5174](http://localhost:5174)

## 🔑 Logging In
- **Email**: `admin@papier.com`
- **Password**: `Papier123!` (or whatever you set on first login)

## 📦 Managing Products

### Add a New Product
1.  Click **Content Manager** on the left menu.
2.  Click **Product** under "Collection Types".
3.  Click **+ Create new entry** (top right).
4.  Fill in the details:
    - **Name**: e.g., "Lavender Wet Wipes"
    - **Price**: 199
    - **Category**: Select from the list.
    - **Image**: Click area to upload/select an image.
    - **Description**: Add text, bold, lists, etc.
5.  **Important**: Click **Save** then **Publish**.

### Edit a Product
1.  Go to **Content Manager > Product**.
2.  Click the pencil icon ✏️ next to the product.
3.  Make changes.
4.  Click **Save**.

### Delete a Product
1.  Select the product(s) using the checkbox.
2.  Click the **Delete** icon (trash can).

---

## 📂 Managing Categories
1.  Go to **Content Manager > Category**.
2.  Click **+ Create new entry**.
3.  Enter **Name** (e.g., "Kitchen Care").
4.  **Slug** will auto-generate.
5.  Upload an **Image**.
6.  Click **Save** and **Publish**.

---

## 🖼️ Changing Images
- You can manage all images in the **Media Library** (left menu).
- To replace an image in a product, edit the product, remove the old image, and select a new one.

---

## ⚠️ Troubleshooting
- **Site not loading?** Check if the black windows are open. If not, run `start-website.bat` again.
- **Changes not showing?** Refresh the website page. Make sure you clicked **Publish** (not just Save).
